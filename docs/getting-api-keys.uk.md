# Як отримати ключі API EcoFlow

[English version](getting-api-keys.md)

Віджету потрібні два ключі з платформи для розробників EcoFlow: **Access Key** і **Secret Key**. Вони безкоштовні, але EcoFlow схвалює акаунти розробників вручну, тож це може тривати від кількох годин до кількох днів.

## Перш ніж почати

Станція має бути додана в **мобільний застосунок EcoFlow** і бути онлайн через Wi-Fi.

Перевірте, під яким акаунтом ви увійшли в застосунок (значок профілю). **Акаунт розробника має бути тим самим акаунтом.** API бачить лише пристрої, прив'язані саме до нього. Реєстрація товару на сайті ecoflow.com - це не те саме, що додавання станції в застосунок.

## Кроки

1. Відкрийте портал для розробників свого регіону:
   - Європа, зокрема Україна: [developer-eu.ecoflow.com](https://developer-eu.ecoflow.com)
   - Інші регіони: [developer.ecoflow.com](https://developer.ecoflow.com)
2. Увійдіть під **тим самим акаунтом**, що й у застосунку EcoFlow.
3. Натисніть **Become a Developer** і заповніть коротку форму. Як мету достатньо вказати щось на кшталт "personal desktop widget for my own power station".
4. Дочекайтеся листа про схвалення.
5. Після схвалення знову увійдіть і відкрийте **IoT Background** (угорі праворуч), потім **Security Information Management**.
6. Натисніть **Create AccessKey**. З'явиться рядок з вашим Access Key.
7. Натисніть значок ока поруч із крапками, щоб побачити **Secret Key**.
8. Скопіюйте обидва ключі у вікно налаштувань віджета.

## Бережіть Secret Key

- Ніколи не публікуйте його в чатах, на скриншотах чи в issues. Сам Access Key нічого не дає, але разом вони дають керування вашою станцією.
- Якщо вважаєте, що Secret Key потрапив до чужих рук, натисніть **Delete** поруч із ним на порталі, створіть нову пару ключів і введіть їх у налаштуваннях віджета (Settings).

## Входите через Google або Apple?

Якщо ви входите в застосунок через "Sign in with Google" або "Apple", EcoFlow може вважати це окремим акаунтом, навіть коли пошта здається тією самою. Якщо віджет не знаходить пристроїв, переконайтеся, що застосунок і портал для розробників використовують однаковий спосіб входу.
